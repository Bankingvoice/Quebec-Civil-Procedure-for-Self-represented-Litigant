# Civil Code of Québec Study Skill · v0.1

## Route the request

- For an overview, study plan, or new lesson, read [the ten-book map and lesson template](references/ten-book-map.md).
- For burden, sufficiency, documentary evidence, inferences, or admissibility, read [Book Seven: Evidence](references/evidence-module.md). Use [the fictional transfer test](references/fictional-bank-transfer.md) for a worked exercise; give the learner the prompt before showing the answer if they want a quiz.
- For an actual dispute, use the relevant module privately with the user's authorized records. If the facts are incomplete, map the gaps rather than assuming they can be filled. Do not bring case material into reusable examples or public artifacts.

## Ground every lesson or application

1. Identify the question and the legal layer: Civil Code (civil rights, obligations and evidence); Code of Civil Procedure (including how proof is handled in proceedings); specialized statute, regulation, and controlling authorities for the particular regime. A general Civil Code rule is not proof that it controls a tax-specific issue. The preliminary provision recognizes complementary and exceptional legislation. If rules may overlap, identify the issue and check how they interact rather than presuming an override.
2. Verify the official [English Civil Code](https://www.legisquebec.gouv.qc.ca/fr/document/lc/CCQ-1991?langCont=en) or [French Civil Code](https://www.legisquebec.gouv.qc.ca/fr/document/lc/CCQ-1991?langCont=fr). Cite the article and applicable date; use article history and transitional rules for past events. A current consolidation is not necessarily the version governing an older event. If unable to verify, say what remains unverified. Do not invent article wording, citations, case holdings or quotations.
3. In study mode, explain in plain language, give one concrete example and a recall check. Use the requested language; by default give English explanations and French equivalents for key terms, with Mandarin clarification when useful. Label any translation or paraphrase; do not call it official text.
4. In application mode, separate **proposition → source/location → what it directly shows → inference/alternative explanation → missing proof → next verification**. Distinguish authenticity or admissibility from weight and sufficiency. Do not infer, just from a bank credit, its purpose, ownership, repayment obligation, or tax character. Distinguish a duplicated accounting entry from the legal and monetary remedy. Identify any procedural or statutory question separately. If the user asks for a tax deadline, distinguish administrative objection, court contestation, and appeal from judgment; verify the governing regime, decision, and triggering event before calculating any date. Do not call a document admitted or a contention proved merely because it is in a working packet.

This Skill is an educational navigation aid. It neither determines legal outcomes nor authorizes filing, contacting anyone, or publishing documents.
